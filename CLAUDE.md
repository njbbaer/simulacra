## Agent Instructions

- Run all Python commands with `uv run`.
- Install dependencies with `uv add <package>`.

## Code Quality

- Run tests with `make test-quiet`.
- Lint and format with `make lint-quiet`.
- Lint and test after making changes.

## Content Directory

`~/simulacra-sync` is the content directory for this framework: characters, prompt templates, and conversation logs. See its `CLAUDE.md` for the layout.
